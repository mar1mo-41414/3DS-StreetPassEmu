# GUI(Windows / macOS / Linux 共通)

```bash
python scripts/gui.py
```

小さなローカルのWebサーバーを起動して、ブラウザで開きます。プロジェクト本体の要件以外には何も
要りません(追加パッケージ、Electron、Tkは不要)。どのOSでも同じ見た目で動きます。待ち受けは
`127.0.0.1`だけで、表示されるURLにはその都度のトークンが入っているので、他のプログラムやWebページ
からは使えません。終了はCtrl+C。オプション: `--workspace DIR`(既定は`./workspace`、git管理外)、
`--port N`、`--no-browser`。

作ったものはすべて**workspace**フォルダに入ります: 保存したBox、Mii、受信したメッセージ
(`received/`)、設定(パスと数値だけ。鍵の値は入りません)。個人情報として扱ってください。
言語(日本語/English)は右上で切り替えられます。

## タブ

| タブ | できること |
|---|---|
| **送受信** | 編集中のBoxを使ってすれちがいループ(`scripts/streetpass_loop.py`)を開始・停止。準備状況の確認、アダプタの確認、設定(チャンネル・待ち受け時間・鍵ファイル等)、受信したBoxの一覧(そのMiiを使う/開いて編集)。 |
| **Mii** | 送信者Miiを選ぶ: **Mii QRコードの画像**(Mii作成の「Miiを送る」)、96/112バイトのMiiファイル、受信したBoxから。ニックネームとIDの表示、Miiファイルの保存。 |
| **Box編集** | あいさつコメント(16文字)、通知文(8文字)、「最後にMiiを設定したアプリ」(名前・タイトルID・バージョン、または**SMDHファイル**の読み込み)、カウンタ、国/地域、3種類のアイコン(画像はブラウザ側で縮小)。 |
| **識別情報** | Miiの`author_id`/`mii_id`(指定、または新規生成。CRC16とAES-CCMタグは自動で作り直し)と、メッセージヘッダの全フィールド(messageId、時刻、フラグ等)。ワンクリックで「新しいID」。 |
| **ファイル** | 空のBoxから開始、Boxファイルを開く、現在のBoxのダウンロード/保存、workspaceの一覧、検証結果(HMAC、Mii CRC16、Miiタグ)。本物のBoxを開くとエディタが扱わない領域もそのまま保持するので、無変更で保存すれば同じバイト列に戻ります。 |
| **ログ** | 送受信ループの出力。 |

Boxはゼロから作れます: Miiを選び、テキストを編集して使うだけです。受信したBoxを雛形にする必要は
ありません。

## 送受信タブに必要なもの

GUIはWi-Fiドライバのセットアップを代行しません。手で打つのと同じコマンドを起動します。引き続き
必要なもの([REQUIREMENTS.md](REQUIREMENTS.md)、[SETUP.md](SETUP.md)):

- `wifit3`のチェックアウト(既定のフォルダは`tools/wifit3`)と`uv`
- 偽装MACにACKを返せるUSB Wi-Fiアダプタ([HARDWARE.md](HARDWARE.md))、Linuxではudevルールまたは`sudo`
- キースロット0x2Eの鍵ファイル。設定でGodMode9で取った`aes_keys.txt`を選ぶと、必要な2行だけを
  workspaceのJSONファイルに取り出します(値は表示しません)

「準備状況を確認」で不足しているものが分かります。「アダプタを確認」はwifit3が見えている対応アダプタを
表示します。編集系のタブはこれらが無くても使えます。

## 限界

- MiiはニックネームとIDだけの表示です(顔の描画には本体のMiiレンダラーが必要)
- 開始/停止は実機のハードウェアを動かす機能で、動作確認は開発者の環境のみです。他のOS・アダプタは
  未検証です([STATUS.md](STATUS.md))
- 本体のIDやファイル名が写るGUIのスクリーンショットやログは、Issueに貼らないでください
